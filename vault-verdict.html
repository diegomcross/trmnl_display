Set bonuses — rate what matters to you

4-pc: keep full slot coverage per archetype+tertiary · 2-pc: keep best per slot+archetype (enough to wear any two) · Ignore: pieces survive only if they beat everything globally for the 180 target · Undecided: protected + flagged. Ratings save automatically.

Exotics — favorite stat tuning

Pick up to three stats that synergize with the exotic's function — first pick is the primary, then secondary, then tertiary. Copies are ranked by the weighted sum: primary ×3 + secondary ×2 + tertiary ×1 (every pick always matters — one huge primary alone doesn't beat two good stats), and only the best copy is kept; the card shows the math. No favorite set: falls back to per-archetype niches and the exotic is flagged pending. Saves automatically.

Tap the ☆ next to an exotic to mark it a favorite exotic (max 7). Diego 2026-08-15: "favorites are set at the floor, the other exotics just help decision with uneeded dupes." Only ★ favorites are aimed at the stat floor and decide which legendaries the declutter engine keeps; every other tuned exotic just settles its own duplicate copies. Star nothing and every tuned exotic drives keeps (the safe default).

Build-driven declutter — preview (read-only)

The engine from docs/ARMOR_DECLUTTER_SPEC.md: for each of your ★ favorite exotics it solves the watched Build Crafter build — or, with no watched build, that exotic's favorite stats aimed at the stat floor — against every set that build picks (or, with no watched build, every set you rated 4-piece / 2-pc only above). Sets never compete: each is solved on its own and every set's picks survive. What those solves actually use is a keep; everything else in a selected/rated set is a junk candidate. Non-favorite tuned exotics only settle their own duplicate copies.
